## 概要


犬を飼い始めるにあたって、事前に準備・把握しておくべきことを整理する。
住まい選びから必要なグッズ、ワクチンや登録などの法的な手続き、幼犬期〜成犬期にかけてやること、しつけまでを順に扱う。
本記事は初めて犬を飼う人を想定した内容で、犬種ごとの細かな違いや医療的な判断までは踏み込まない。具体的なワクチンのスケジュールや体調面の判断は、かかりつけの動物病院に相談するのが前提となる。

## 住まい選び

### ペット可の物件

- 賃貸物件で犬を飼う場合、まず「ペット可」の物件であることが大前提となる
  - ペット不可の物件で無断で飼育すると契約違反となり、退去や違約金の対象になりうる
- 「ペット可」と「ペット相談」は意味が異なる
  - **ペット可**：ペットの飼育を前提とした物件。ただし条件付きのことが多い
  - **ペット相談**：大家・管理会社との交渉次第。小型犬1匹まで、猫は不可、といった条件で許可されることが多い
- 契約前に確認しておくべき項目

| 項目 | 確認内容 |
| --- | --- |
| 飼育できる種類 | 犬のみ・猫のみ・小動物のみなど、種類が限定されていないか |
| 頭数・サイズ制限 | 「小型犬1匹まで」「体重10kgまで」「体高〇cmまで」などの制限 |
| 敷金・礼金 | ペット飼育の場合は敷金が1ヶ月分上乗せされることが多い |
| 原状回復費用 | 退去時の床・壁の傷や臭いのクリーニング費用がどこまで借主負担になるか |
| 管理規約 | 共用部では抱っこ必須、エレベーターはペット表示ボタンを押す、などのルール |
| 近隣の環境 | 散歩コース・公園・ドッグラン・動物病院（夜間救急含む）が近くにあるか |

- 分譲賃貸の場合、大家の許可があってもマンション全体の管理規約で飼育が制限されていることがあるため、管理規約まで確認しておくと安心
- 犬の寿命は10〜15年以上あるため、引っ越しの可能性も含めて長期的に住まいを考えておく必要がある
  - ペット可物件は数が限られ、家賃も相場より高めになる傾向がある

### 物件の防音性（近隣トラブル）

- 犬を飼う上で最も起こりやすい近隣トラブルが「鳴き声」と「足音」
  - ペット可物件であっても、他の住人がペットを飼っているとは限らず、音への許容度は人によって異なる
- 建物の構造によって防音性は大きく変わる

| 構造 | 防音性 | 特徴 |
| --- | --- | --- |
| RC造（鉄筋コンクリート） / SRC造（鉄骨鉄筋コンクリート） | 高い | 壁・床が厚く、鳴き声や足音が伝わりにくい |
| 鉄骨造 | 中程度 | 壁の素材次第で差が大きい。軽量鉄骨は木造に近い |
| 木造 | 低い | 鳴き声・足音ともに伝わりやすい |

- 部屋の位置も重要
  - **角部屋**：隣接する部屋が少なく、鳴き声が伝わる範囲を減らせる
  - **1階**：階下への足音を気にしなくてよい
- 入居後にできる対策
  - 床にジョイントマットやラグ、防音マットを敷く
    - 足音の軽減だけでなく、フローリングでの滑りを防ぎ、関節（特に小型犬に多い膝蓋骨脱臼）への負担を減らす効果もある
  - ケージを隣室と接する壁から離して設置する
  - 窓際に置かない（外の音や通行人に反応して吠えるのを防ぐ）
- 入居時に両隣・上下の部屋へ挨拶をしておくと、万一のときにも関係がこじれにくい
- 根本的な対策は、後述する「吠えさせないためのしつけ」になる

## 飼うために必要なもの

迎える前に一式揃えておき、来た日から生活できる状態にしておく。

### 必須のもの

| 分類 | もの | 補足 |
| --- | --- | --- |
| 生活スペース | ケージ / サークル | 犬が安心して過ごせる居場所。留守番時や夜間の寝床にもなる |
| 生活スペース | クレート（キャリー） | 通院・移動時に使う。普段からクレートに慣らしておくと災害時の避難にも役立つ |
| 生活スペース | ベッド・毛布 | ケージ内に置く。噛んで誤飲しにくい素材を選ぶ |
| 食事 | 水飲み（給水器） | 器タイプとノズルタイプがある。ケージに固定できるものだとひっくり返されない |
| 食事 | フード皿 | 陶器やステンレスなど重めで倒れにくいもの |
| 食事 | ドッグフード | 迎える前にペットショップ・ブリーダーで食べていたものと同じものを用意する |
| 食事 | おやつ | しつけのご褒美として使う。小さくちぎれるものが便利 |
| トイレ | トイレトレー | シートを固定できるメッシュ付きのものだと、シートを噛んだり破いたりしにくい |
| トイレ | トイレシート | 消耗品なので多めに。レギュラー / ワイドなどサイズに注意 |
| トイレ | 消臭スプレー | 粗相した場所の臭いを残さないために使う（臭いが残ると同じ場所で繰り返す） |
| おもちゃ | 噛むおもちゃ | ロープ・ラバー製など「噛んでいいもの」。甘噛み対策として重要 |
| おもちゃ | 知育玩具 | フードを詰めて遊ばせるタイプ。留守番中の退屈しのぎになる |
| 散歩 | 首輪 / ハーネス | 首輪はリードからの合図が伝わりやすく、引っ張り癖を直すしつけに向く。ハーネスは首への負担が少ないが、体全体で引っ張れるため引っ張り癖がつきやすい。気管が弱い小型犬はハーネスを選ぶ |
| 散歩 | リード | 伸縮リードは慣れるまで制御が難しいため、最初は通常のリードがおすすめ |
| 散歩 | 迷子札 | 飼い主の連絡先を記載したもの |
| お手入れ | ブラシ・爪切り・歯ブラシ | 子犬のうちから触られることに慣らしておく |
| お手入れ | シャンプー | 犬用のもの。子犬はワクチン完了までは基本的に部分洗いにとどめる |

### 小型犬の場合にあると良いもの

- **フードプレッサー（フードクラッシャー）**
  - ドライフードを砕いて細かくする道具
  - 小型犬や超小型犬（チワワ・トイプードル・ヨークシャーテリアなど）は口が小さく、粒が大きいと丸飲みしたり食べにくかったりするため、粒を砕いてあげると食べやすくなる
  - ふやかしたフードを潰してペースト状にする用途でも使える
- **ペットゲート（ペットフェンス）**
  - キッチンや階段など、入ってほしくない場所への侵入を防ぐ
- **滑り止めマット**
  - 前述の通り、関節への負担軽減と防音を兼ねる

### あると安心なもの

- ペット保険
  - 犬は公的な医療保険が無く、治療費は全額自己負担になる。子犬期は誤飲などで急に通院が必要になることも多い
- ペットカメラ
  - 留守番中の様子を確認できる。吠えているかどうかの把握にも使える
- 誤飲防止のためのコードカバー・コンセントカバー

## ワクチン接種・狂犬病

### 犬の登録と狂犬病予防注射（法律上の義務）

- 狂犬病予防法により、以下が飼い主の**義務**として定められている
  - 生後91日以上の犬を飼い始めたら、**30日以内に市区町村へ犬の登録**をする（生涯1回）
  - **毎年1回、狂犬病予防注射**を受けさせる（例年4〜6月が接種期間）
  - 登録時に交付される**鑑札**と、注射後に交付される**注射済票**を犬に装着する
- 登録は住所地の市区町村（保健所など）で行う。動物病院で予防注射と登録手続きをまとめて代行してくれる自治体もある
  - 自治体によっては、マイナポータル（ぴったりサービス）からマイナンバーカードを使ってオンライン申請することもできる。対応状況は市区町村ごとに異なるため、マイナポータル上で住んでいる地域を指定して確認する
- 引っ越しをした場合は、転居先の市区町村で所在地の変更届けが必要
- 違反した場合は20万円以下の罰金の対象となる

### 狂犬病とは

- 狂犬病ウイルスによる感染症で、犬だけでなく人を含むすべての哺乳類に感染する
- 発症するとほぼ100%死亡する、極めて危険な病気
- 日本では1957年以降、国内での感染例は確認されていないが、世界では現在も毎年数万人が亡くなっている
  - 海外からウイルスが持ち込まれる可能性は常にあるため、予防注射によって国内の犬の免疫水準を保つことが重要になっている

### マイクロチップ

- 2022年6月から、ペットショップやブリーダーなどの販売業者に対して、販売する犬・猫へのマイクロチップ装着・情報登録が義務化された
- 販売業者から犬を購入した場合、飼い主は取得した日から**30日以内に所有者情報の変更登録**を行う必要がある
  - 販売業者は、引き渡し時に「登録証明書」を購入者へ渡すことが義務付けられている
  - ペットショップによっては、購入時の手続きの中で変更登録を代行してくれる（無料の場合も、手数料がかかる場合もある）
  - ただし変更登録の義務は飼い主側にあるため、代行してもらった場合でも、登録証明書を受け取っているか、所有者情報が自分の名前に変わっているかを確認しておく
  - ブリーダーから直接迎えた場合や、代行が無い場合は自分で手続きする。オンライン申請なら手数料300円（紙での申請は1,000円）
- 自治体によっては、マイクロチップの登録をもって犬の登録（鑑札の交付）とみなす「ワンストップサービス」に参加している

### 混合ワクチン（任意だが推奨）

- 狂犬病以外の感染症（ジステンパー・パルボウイルス感染症・犬伝染性肝炎など）を予防するためのワクチン
- 法律上の義務ではないが、ドッグラン・トリミングサロン・ペットホテルなどでは接種証明の提示を求められることが多い
- 一般的な子犬期のスケジュール
  - 母犬からもらった免疫（移行抗体）が切れていく時期に合わせ、生後6〜8週頃から**3〜4週間隔で2〜3回**接種する
  - 最終接種は生後16週以降になるように調整することが多い
  - その後は1年後に追加接種し、以降は1〜3年ごとに接種する
- 何種混合を打つかは、生活環境（山や川に行くか、他の犬とどれくらい接触するか）に応じて動物病院と相談して決める

### その他の予防

- **フィラリア予防**：蚊が媒介する寄生虫。蚊の出る時期（地域によるが5〜12月頃）に月1回の予防薬を投与する
- **ノミ・マダニ予防**：散歩で草むらに入る場合は特に必要。フィラリアとまとめて予防できる薬もある

## 幼犬期〜成犬期にやること

子犬を迎えるのは、生後2〜3ヶ月頃が一般的。そこから成犬（小型犬で生後10ヶ月〜1年、大型犬で1年半〜2年程度）になるまでに、以下のようなことを行う。

### 時期ごとの目安

| 時期 | 主なこと |
| --- | --- |
| 迎えた直後（数日〜1週間） | 環境に慣れさせる期間。構いすぎず、ケージ内でゆっくり休ませる。最初の健康診断を受ける |
| 生後2〜4ヶ月 | 混合ワクチン接種。社会化期のピーク。トイレトレーニング開始。名前を覚えさせる |
| 生後3ヶ月〜 | 狂犬病予防注射・犬の登録（生後91日以上になったら30日以内） |
| ワクチン完了後（2週間程度空けて） | 散歩デビュー。地面を歩かせる、他の犬や人と接する |
| 生後4〜6ヶ月 | 乳歯から永久歯への生え変わり。甘噛みが増える時期なので噛んでいいおもちゃを与える |
| 生後6ヶ月頃〜 | 食事回数を1日2回へ減らしていく。避妊・去勢手術を検討する時期 |
| 生後10ヶ月〜1年（小型犬） | 子犬用フードから成犬用フードへ切り替え |

### 食事（ウェットフード・ふやかし）

- 迎えた直後は環境の変化でストレスがかかり、お腹を壊しやすい。ペットショップ・ブリーダーで与えていたフードを、同じ量・回数で与えるところから始める
  - フードを変える場合は、元のフードに新しいフードを少しずつ混ぜ、1〜2週間かけて切り替える
- 子犬は一度にたくさん食べられず、低血糖にもなりやすいため、1日の量を**3〜4回に分けて**与える
- 生後2〜3ヶ月頃は、ドライフードを**ぬるま湯でふやかして**柔らかくして与えるのが一般的
  - 歯や消化機能が未発達なため
  - 熱湯はフードの栄養素を壊すことがあり、やけどの原因にもなるので避ける
  - 前述のフードプレッサーで砕いたり潰したりすると、さらに食べやすくなる
- ウェットフードは嗜好性が高く水分も摂れる一方で、それだけでは栄養が偏るものもある（「総合栄養食」と表記されているものを選ぶ）。ドライフードのトッピングとして使うのも手
  - 最初からウェットフードに慣れさせすぎると、ドライフードを食べなくなることがあるので注意
- 生後4ヶ月頃から徐々にふやかす時間を短くし、ドライフードのまま食べられるように移行していく
- 人の食べ物は与えない。特に**玉ねぎ・ネギ類、チョコレート、ぶどう・レーズン、キシリトール**などは犬にとって中毒の危険がある

### 社会化

- 生後3週〜12週頃（〜14週程度）は「社会化期」と呼ばれ、さまざまな物事を抵抗なく受け入れやすい時期
  - この時期に経験したことは「怖くないもの」として覚えやすく、逆にこの時期を逃すと、知らないものへの警戒心から吠えや噛みにつながりやすい
- ワクチン完了前で地面を歩かせられない時期でも、**抱っこ散歩**で外の音・人・車・他の犬などを見せることはできる
- 家の中でも以下のようなことに慣らしておく
  - 掃除機・インターホン・ドライヤーなどの生活音
  - 体（足先・耳・口の中・しっぽ）を触られること
  - ブラッシング・爪切り・歯磨き
  - クレートに入ること、車に乗ること
- 怖がった場合は無理強いせず、距離を取ったり、おやつを使って「良いことが起きる」と結びつけながら段階的に慣らす

## しつけ

### 基本的な考え方

- **褒めて教える**のが基本。できたら即座に（目安として3秒以内に）褒めて、おやつやなでることでご褒美を与える
  - 時間が空くと、何を褒められたのか犬には分からなくなる
- 叩く・大声で怒鳴るといった罰は逆効果
  - 飼い主への恐怖心や不信感につながり、手を怖がって噛むようになる原因にもなる
- 家族全員で**ルールと合図（言葉・ハンドサイン）を統一**する
  - ある人はソファに乗せる、ある人は叱る、といった状態だと犬が混乱する
- 1回のトレーニングは数分程度の短時間で、1日に何度か繰り返す。子犬の集中力は長く続かない

### 基本のコマンド

| コマンド | 教え方の例 | 役立つ場面 |
| --- | --- | --- |
| 名前 | 名前を呼んでこちらを見たら褒める | すべてのしつけの基礎。注意を向けさせる |
| おすわり | おやつを鼻先から頭の上へゆっくり動かし、自然にお尻が床についたら「おすわり」と言って褒める | 興奮を落ち着かせる。食事前・道路を渡る前など |
| ふせ | おすわりの状態から、おやつを鼻先から床へ下ろし、体が伏せたら褒める | 長時間待たせたいとき。カフェなど |
| まて | おすわりの状態で手のひらを見せて「まて」と言い、1秒待てたら褒める。徐々に時間と距離を延ばす | 飛び出し防止・食事前など、安全面で特に重要 |
| おいで | 名前を呼び、来たら大げさに褒める。呼んで来た後に嫌なこと（叱る・爪切りなど）をしない | リードが外れたときなど、緊急時に呼び戻す |
| お手 | 前足が上がったタイミングで手のひらで受けて褒める | 実用性は高くないが、足を触られることに慣れる・コミュニケーションになる |

- 最初はおやつで誘導し、できるようになったらおやつ無しで言葉・ハンドサインだけでできるようにしていく

### トイレのしつけ

- 子犬は膀胱が小さく、我慢もできないため、失敗するのは当たり前という前提で取り組む
- 排泄しやすいタイミングで**トイレに連れて行く**
  - 寝起き
  - 食事・水を飲んだ後
  - 遊んだ後
  - そわそわして床の匂いを嗅ぎ回ったり、くるくる回り始めたとき
- 成功したらすぐに褒めてご褒美を与える
  - 「ワンツー」など排泄を促す合図の言葉をかけると、将来的に合図で排泄できるようになり、外出先で便利
- 失敗しても**叱らない**
  - 叱られると「排泄すること自体」が悪いと覚え、隠れて排泄したり、飼い主の見ていないところでするようになる
  - 無言で片付け、消臭スプレーで臭いを完全に消す（臭いが残っていると同じ場所をトイレと認識する）
- 最初はケージ内をトイレと寝床に分け、トイレの場所を覚えたら徐々に行動範囲を広げていく

### 甘噛み・手遊びについて

- 子犬の甘噛みは、歯の生え変わりによるむず痒さや、遊びの延長として自然に起こる行動
- ただし**手で遊ぶ（手遊び）のは良くない**
  - 手をおもちゃにして遊ぶと、「人の手は噛んでいいもの」と学習してしまう
  - 子犬のうちは痛くなくても、成犬になると力が強くなり、ケガにつながる。来客や子どもを噛むリスクにもなる
- **噛んでいいもの / いけないものを区別させる**
  - 遊ぶときは必ずおもちゃ（ロープ・ラバー製の噛むおもちゃなど）を介して遊ぶ
  - 手や服、家具を噛んだら、その瞬間に遊びを中断する（無言で立ち去る・手を引っ込める）
    - 「噛むと楽しい時間が終わる」と覚えさせる
  - 噛んでいいおもちゃを差し出して交換し、おもちゃを噛んだら褒める
- 噛まれたくない家具やコード類は、そもそも届かない場所に置く・カバーをするなど、失敗させない環境づくりも重要
- 噛む欲求自体は犬の本能なので、禁止するのではなく「噛んでいい対象」に向けてあげることが大切

### 吠えさせないために

- 吠えには理由があり、原因ごとに対策が異なる

| 吠えの種類 | 原因・状況 | 対策 |
| --- | --- | --- |
| 要求吠え | ご飯・遊び・ケージから出してほしいなど、要求を通したい | 吠えている間は**応じない・目を合わせない**。静かになった瞬間に応じたり褒めたりする |
| 警戒吠え | インターホン・足音・通行人など、知らない音や人への警戒 | 社会化期に音や人に慣らしておく。窓の外が見えないようにする。インターホンの音とおやつを結びつけて慣らす |
| 不安・分離不安 | 飼い主の姿が見えなくなる・留守番が不安 | 短時間の留守番から少しずつ慣らす。外出・帰宅時に大げさに声をかけない |
| 退屈・運動不足 | エネルギーが余っている | 散歩や遊びで十分に運動させる。知育玩具で頭を使わせる |

- 要求吠えに一度でも応じてしまうと、「吠えれば要求が通る」と学習し、さらに強く吠えるようになる
  - 近所迷惑を気にして吠えるたびに応じてしまうのが、最もやってはいけないパターン
- 「静か」「おいで」「おすわり」など、吠えている状態から別の行動に切り替えさせるコマンドを教えておくと有効
- 叱って止めようとすると、犬は「飼い主も一緒に吠えている（反応してくれている）」と受け取ることがあり、かえって吠えが強化されることがある
- 吠え癖は成犬になってから直すのは時間がかかるため、子犬のうちから対策しておくことが、前述の近隣トラブル防止にも直結する

### パピートレーニング・しつけ教室

- 自己流で難しい場合は、動物病院やペットショップが開催している**パピー教室**や、ドッグトレーナーによるしつけ教室を利用するのも手
- 他の子犬と触れ合う機会にもなり、社会化の面でもメリットがある

## さいごに

- 犬を飼うことは10〜15年以上続く責任であり、迎える前の準備（住まい・グッズ・手続き）で飼育のしやすさが大きく変わる
- 住まいは「ペット可」であることに加え、構造（RC造など）や部屋の位置といった防音性も含めて選ぶと、近隣トラブルのリスクを下げられる
- 犬の登録と年1回の狂犬病予防注射は法律上の義務。混合ワクチンやフィラリア・ノミダニ予防も含めて、かかりつけの動物病院を早めに見つけておくと安心
- 幼犬期は、食事（ふやかし・回数）への配慮と、社会化期を活かしたさまざまな経験が、その後の性格や問題行動の少なさにつながる
- しつけは「褒めて教える」「家族でルールを統一する」「失敗させない環境を作る」が基本。特に手遊びを避けて噛んでいいものを区別させること、要求吠えに応じないことは、子犬のうちから意識しておきたい
