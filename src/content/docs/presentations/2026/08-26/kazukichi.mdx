## はじめに

- ※ この記事の内容は半年以上前に行ったことです
- ある日、スパイシーな漢ってかっこいいよなと思った
- そこでスパイスをふんだんに使える料理について考えていたが、ふとクラフトコーラが頭に浮かんだ
- コーラの持つ原材料のミステリアスさに惹かれて作ってみることにした

## 作り方

### 前提

- シロップ500ml(炭酸で割れば約1.5〜2L分)作る場合
- 私は今回、倍量作りましたが、上記の前提でお話します

### 材料

- シナモンスティック ... 1本(約4〜6g)
- クローブ(ホール) ... 5〜7粒(約1g)
- カルダモン ... 3〜5さや(約1〜1.5g)
- ジンジャー ... スライスで20〜30g(親指大1かけ)
- バニラビーンズ ... 1/2本(またはエッセンス小さじ1/2)
- レモン ... 1個(果汁 + 皮)
- 砂糖(きび砂糖か三温糖) ... 200〜250g
- メープルシロップ(後輩のカナダ土産を使った) ... 適量
- はちみつ ... 適量
- 五香粉 ... お好みで。エキゾチックさが出せるが入れすぎると中華料理になるよ

### 手順

- レモンの皮と果汁を分離する

- 鍋に水300ml + 果汁以外の全てを入れて10〜15分煮る
